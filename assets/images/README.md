# Demo image guidance

The visual demo uses remote stock photography to demonstrate how the template handles diverse salon audiences, including Black beauty imagery and Indian representation. These are placeholders, not Maggie-specific client photography.

## Replacement points
- `index.html` hero and editorial images
- `pages/services.html` service / salon imagery
- `pages/gallery.html` gallery imagery
- `pages/about.html` story and representation imagery
- `pages/contact.html` contact imagery

## Current sources
- Unsplash: free stock imagery under the Unsplash License. Existing image IDs are listed below for provenance tracking.
- Rawpixel: one AI-generated Indian salon image is used as a visual placeholder and is marked for replacement. The source page currently states free business use but also disclaims warranties for AI-generated content. Treat it as demo-only and replace before commercial delivery.

## Commercial rule
Replace all remote demo imagery with buyer-approved, properly licensed assets before a production launch or resale package. Keep ordinary `<img>` elements, explicit dimensions, descriptive `alt` text and `object-fit: cover` so asset replacement remains simple.
