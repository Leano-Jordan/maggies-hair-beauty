# Maggie’s Hair & Beauty

A reusable, progressively enhanced static commercial website foundation for salons, barbers, beauty studios, spas and nail businesses.

## Run locally

Open `index.html` directly, or use VS Code Live Server for the best local development experience.

## Stack

HTML5, CSS3 and vanilla JavaScript. No backend or build system.

## Important

Maggie’s is fictional demo content. Replace business information, prices, testimonials and images before commercial use.
